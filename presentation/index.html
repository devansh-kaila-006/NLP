Implementation Details

8

Technology Stack

  • Embeddings: all-MiniLM-L6-v2 (384 dimensions)
  • Vector Store: FAISS IndexFlatIP (exact search)
  • Reranking: ms-marco-MiniLM-L-6-v2, ms-marco-electra-base
  • LLM: Gemini 3.1 Flash Lite Preview
  • Graph Processing: NetworkX for temporal dependencies

Data Sources

  • 9,661 PDF Chunks: Stanford CS229 notes, Deep Learning textbook, documentation
  • 2,923 Video Chunks: 5 complete Stanford/MIT courses
  • 133 Web Chunks: Aman.ai modern AI primers
  • Total Storage: ~5GB for indices and data
